- Preserve accounts, settled bills, member financial/pass history, inventory and audit history. Member deletion must reject nonzero balances, remaining passes and unsettled linked business.
- Force clear affects only the selected band, including linked-party cases; retain existing explicit stock-return behavior.
- Cashier/inventory may edit all catalog kinds but must not acquire refund/report/employee/reset privileges.
- Staff see only eligible activated bands and only the wristband page, with backend opening/managing denied.
- No automatic cloud changes. Original release trust, profile/architecture and sequence checks remain enforced. No Win7 build.
