# 桌面 0.4.5 优化（用户已确认）

更新采用现有 0.4.4 自动更新通道：启动后检查已签名发布策略，联网下载、覆盖安装，不卸载、不清空终端及打印设置。只交付 Win10/Win11 x86/x64，保留原更新公钥、平台通道与单调发布序号。新登录页另提供“检查更新”入口；旧页面第一次升级依靠其原有启动检查。

1. 管理员、库管、收银员在激活或挂失手牌上直接看到“强制清空”，核对当前登录账号密码，仅取消该手牌未结订单、恢复该手牌，其他联动手牌不变。
2. 会员详情后添加删除：逻辑归档，保留历史账目和审计。余额不为零、任何剩余次卡次数、未完成关联业务时拒绝删除；先处理余额/权益，不能无偿抹除。
3. 项目商品操作后添加删除：逻辑归档，不破坏历史订单、库存主数据和历史流水；当前账号密码核对，不能重新启用已删除项。
4. 这三类管理角色可修改所有既有项目种类的名称、价格、状态等；已结账快照不变，未结账沿用现有实时重算。
5. 库存摘要只保留“库存项目”“低库存”，并排显示。
6. 搓澡师、三楼服务员只有前台手牌：仅看到权限范围内已激活手牌，只能加单，不能开牌或管理手牌；服务范围、男女浴隔离仍由服务器强制执行。
7. 经营重置保留所有库存主数据、结存、包装规格及历史库存流水；其余重置行为保持不变，界面预览明确说明保留库存。

安全：验证本人密码、失败限流沿用既有机制；写操作使用现有交易锁/版本控制、追加审计、实时同步。独立清空/删除权限不授予退款、报表、员工管理等额外权限。所有现存账号、金额、审计记录原样保留。只本地开发交付，由用户执行 PowerShell 发布；不自动连接修改 ECS。
