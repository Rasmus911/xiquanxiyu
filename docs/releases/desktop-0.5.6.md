# 0.5.6 溪泉图标与库存布局

更新日志：

1. 给桌面端的图标做出更换
2. 优化“库存”页面布局

桌面为 Win10/Win11 的 x86/x64 四个独立安装包，保留原安装身份及更新签名公钥。不提供 Win7。本版安卓为 1.2.13（版本码20），保留原证书，旧 APP 内下载后由系统确认覆盖安装。

库存数量仅去掉无意义小数零，真实小数不舍入。成本保留小数。盘点表使用当日北京时间、包装成本/最大单位、基本单位数量；隐藏ID/记录版本/匹配校验码仍保留。旧列名仍可导入；减少25%或以上确认及修改已有成本的密码核验仍保留。

本机完整发布指令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\溪泉洗浴系统\最新版安装包-溪泉图标与库存布局-0.5.6\完整发布指令.ps1"
```

按提示输入 `PUBLISH CLOUD 0.5.6`、`PUBLISH 0.5.6`、`PUBLISH ANDROID 1.2.13`；签名及证书密码只在本机隐藏提示中输入。

本版无数据库结构迁移、重置或业务清空。云端步骤仅替换库存表格导出代码及网页静态文件，原运行设置冻结保留，离线复用当前API镜像。失败最多回退本次代码/镜像，不回滚数据库。

已上传、仅公开网页校验失败时：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\溪泉洗浴系统\最新版安装包-溪泉图标与库存布局-0.5.6\01-部署云端.ps1" -VerifyOnly
```

已发布桌面更新、仅公开下载校验失败时：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\溪泉洗浴系统\最新版安装包-溪泉图标与库存布局-0.5.6\02-签名并发布桌面更新.ps1" -Mode verify
```

安卓构建未上传时，只执行03；构建已成功、上传失败时可用03 `-Mode publish`，沿用相同APK。失败后不要重跑全部流程、不换证书、不清空更新序号。

本机交付校验、签名完成、上传完成、公网验证、真实设备覆盖安装是不同状态。网络及现场设备仍需实际验收，不能保证所有历史客户端永不出现设备/网络错误。

历史公共安装包按版本分块归档至指定 GitHub，单块不超过32MiB，远端重组SHA256核验后才清理。本机私有签名密钥、真实库存、备份和云端恢复证据不上传、不删除；当前发布依赖的旧工具属于最新版本的必要依赖，不能只按文件名旧版本号删除。
