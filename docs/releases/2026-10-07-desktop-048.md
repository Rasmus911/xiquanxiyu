# 0.4.8 下单与库存优化

## 本次内容

1. 澡巾、备品、搓泥宝按服务项目下单，不显示商品数量选择。
2. 点击加单后，在耗材弹窗确认当前手牌及耗材；取消不下单，联动切牌不串单。
3. 库存项目和项目商品每页10项，分页移到列表右上角。
4. 库存显示基本单位成本单价；首次设置免密码（包括0元），后续改价验证当前登录账号自己的密码。成本修改有审计记录，不改历史入库成本。
5. 网页与手机对应内容同步，Android版本1.2.6（code13），原证书覆盖安装。

## 不变的内容

本次不清空订单、会员、储值、次卡、库存数量、员工或审计记录。数据库从20261007_insights_cost加法迁移到20261007_ordering_cost：增加可空成本字段，并仅转换三个指定项目的分类，价格及历史账单不变。旧库存未设置成本显示“未设置”，不把它当成0元。

四个桌面包：Win10/Win11各32位、64位，不新增Win7包。桌面使用原发布公钥及原更新地址；发布脚本读取线上已签名策略，递增序号并保留最低支持版本，不猜测序号。
