# 手机端 1.2.8：注册令牌入口修复

范围仅为手机 APK 与移动页面、手机 bootstrap 权限返回。桌面端版本保持 0.4.9，数据库结构、管理员名单和共享令牌的 180 秒轮换均不变。

## 修复内容

- 底部导航新增“注册令牌”，页面标题及“我的”页按钮统一使用该名称。
- 底部入口要求已登录、服务端明确授权，且登录用户名精确为 18631459666 或 18603346509。
- 服务端仍检查实际手机通道、启用的受保护管理员身份及绑定关系；其他账号不会因角色为管理员而得到令牌。
- 修复 `/api/mobile/bootstrap` 未返回 `registration_token_view` 导致刷新数据覆盖登录权限的问题。
- 六个底部入口按可用宽度均分，避免窄屏被固定宽度挤出。

## 单独发布方式

使用 `scripts/mobile-128-entry.ps1` 与本次交付目录内的“交付信息.json”。不要复用仍固定为 1.2.7 的桌面 0.4.9 安卓发布脚本。

1. `-Mode api`：校验准确旧源码与新文件，沿用当前健康 API 镜像依赖，离线构建仅覆盖一个 Python 文件的镜像；在重启前对比运行配置。保留私有检查点，失败时仅恢复原代码和镜像，不恢复数据库。
2. `-Mode build`：用原安卓证书构建 1.2.8/code15；密码仅在本机隐藏提示中输入。校验证书与 1.2.7 连续性、实际包名、版本及发布文件哈希。
3. `-Mode publish`：验证云端实际 API 文件，上传并校验 APK、下载配置与移动页面压缩包；保留旧 APK 和缓存页面需要的旧哈希资源，仅合并 Android 更新策略，不覆盖桌面和网页更新策略。

最小允许版本仍为 code9。本次只增加新版本，不让旧版设备卸载；已支持应用内更新的旧 APP 下载后由 Android 弹出覆盖安装确认。

## 上传卡顿修正

原入口每个文件先等待 SCP 退出，再建立新 SSH 连接校验，缺少阶段提示且没有总等待上限。用户实测 SSH 可连接，但文件上传 100% 后仍长时间没有输出；仅凭旧日志无法区分 SCP 退出等待与后续校验连接。

现改为 SSH 标准输入上传到私有暂存目录，在同一连接内校验文件 SHA256。小文件总上限 90 秒，大于 1 MiB 的 APK/页面文件上限 300 秒；私有目录准备及运行镜像检查上限 45 秒。每 15 秒提示等待时间，显示上传、校验通过、开始执行补丁等边界。不自动重试部署、不跳过 SHA 校验，超时仅终止本机传输进程。真正执行云端补丁仍保留原有实时输出和私有恢复证据，不在中途强杀服务器部署进程。

## 云端健康验证协议修正（2026-10-09）

用户提供的私有失败证据显示，API 补丁验证被 `curl` 的 HTTP/2 错误（退出码 16）中断；原镜像已经恢复、API 健康，Nginx 配置检查成功，随后同源健康请求返回 HTTP 200。候选环境和进程配置也没有差异。

仅将窄 API 补丁的同源健康验证固定为 HTTP/1.1，保留 HTTPS 证书验证、域名 SNI、HTTP 错误检测及 20 秒超时。数据库、管理员名单、令牌算法和 APK 源码不变。原代码与镜像恢复已经确认后，使用更新后的 `01-修复云端令牌权限.ps1` 重新执行这个窄补丁；不运行旧的数据库部署/恢复脚本。
