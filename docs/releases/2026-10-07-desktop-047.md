按顺序执行，不在 ECS 的 Linux 窗口执行以下指令。


提示时输入 `UPDATE 0.4.7`。脚本自动取得新暂存路径，先在原服务正常时利用原镜像已验证的依赖离线构建，再暂停写入、备份、实际隔离恢复演练、升级结构及核对保留数据，最后恢复 API 和网页。新结构为 `20261007_insights_cost`，原结构须为 `20261007_desktop_ops`。不清空业务、账号或库存数量，不重放旧库存维护任务。备份及迁移期间请勿开单。首次初始化库存预警为最近采购/期初入库基本数量的15%；无流水的旧库存仅首次以现存量兜底，后续销售、退库和重启不重算。历史类别、包装规格和流水仍保留。

## 功能与核验

1. 收银员、库管增加经营报表；员工管理、审计、重置、退款等权限不扩大。手机已获准通道的对应账号同步报表；搓澡师及服务员不获得管理权限。
2. 报表分开消费净营收、新增资金、充值与余额核销，防止钱重复计算。合并2个手牌结账算2人次，客单营收按人次计算。对比前一等长期间，入場时段为北京时间，会员关联占比不叫复购率。项目排行可按金额或份数查看。采购成本独立展示，不把采购当作耗用成本或推算利润。未设置成本明确计为未设置笔数。
3. 桌面与手机库存每页15条，搜索回到第一页。新增不填类别或原始包装规格；使用基本单位、包装单位、每包装基本单位数即可。行操作分开入库、编辑、历史、归档。
4. 每次采购/期初入库更新预警为本次折算数量15%，向上保留三位小数。4箱×200袋=800袋，预警120袋。退回和出库不重置该线。
5. 入库成本选填，按当前输入单位填单价。如4箱×120元/箱=480元，基本单位单价0.60元/袋；留空不等于0，明确0可记录。历史入库可补录/更正，保留操作人、时间、前后金额及原数量与换算。网络重试不重复入库或重复记成本。切换输入单位会清除尚未提交单价，避免箱价误当袋价。
6. 入库原因使用采购、误出库退回、盘点、破损/过期等选项，匹配实际类型；手牌强制清空原因使用误开牌、测试、客人取消入场，仍须本人密码，仅清当前手牌。
