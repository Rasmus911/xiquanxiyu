# 溪泉洗浴历史版本归档

源码按 `desktop/<版本>/source-<版本>.zip` 分类；安卓安装包按 `android/<版本>/` 分类。

历史桌面安装包位于 `desktop/<版本>/installers/`。为避免超过单文件上传大小，安装包使用最多 **32 MiB** 的 `.part001`、`.part002` 等原始字节分片，不是独立安装程序。

## 恢复桌面安装包

下载同一版本 `installers` 文件夹内的全部分片、`parts-manifest.json` 和 `合并归档安装包.ps1`，放到同一个本机文件夹。在该文件夹执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\合并归档安装包.ps1"
```

脚本先验证每个分片的字节数与 SHA256，再按序合并，最后验证完整 EXE 的字节数及 SHA256。校验失败不要安装；脚本不会覆盖不匹配的既有 EXE。

GitHub Releases 中已发布的完整安装包也可直接下载。`versions.json` 记录版本及完整包校验信息；分片清单记录各分片校验信息。历史版本仅用于归档，不会替代 ECS 的正式更新通道。
