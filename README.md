# 溪泉洗浴管理系统

面向单店、多终端的洗浴收银与经营管理系统，覆盖男女浴手牌、消费、统一结账、58mm 小票、会员储值/次卡、库存、经营报表和不可编辑审计记录。

当前待发布桌面版本为 **0.5.1**（Win10/Win11，32/64位），安卓保持 **1.2.9/code16**。四个安装包和完整部署指令位于 `最新版安装包-实体卡消费-0.5.1`；本次说明以 [0.5.1交付与PowerShell](docs/releases/desktop-0.5.1.md) 为准。构建完成不代表云端部署或原私钥签名发布已经完成。

## 技术栈

- Vue 3 + TypeScript + Element Plus + Electron
- Python 3.12 + Flask + SQLAlchemy + Flask-SocketIO
- PostgreSQL（正式营业）/ SQLite（快速开发与自动测试）

## 已实现模块

- 员工独立账号、岗位权限、登录入口限制、失败锁定和服务端权限校验；支持账号密码修改。
- 登录凭证只保存在当前运行内存中；刷新、关闭页面或重启客户端 EXE 后必须重新登录。
- 男浴001–050、女浴051–100，支持手工开单、换牌、挂失赔偿、恢复和补牌。旧手牌迁移须显式确认，不能直接覆盖未结账订单。
- 前台提供“多选联动”模式：先选男浴、切换女浴后继续选择，一键建立跨区联动；空闲牌自动开单，并支持联动消费汇总与整组结账。每张激活手牌实时显示使用时长。
- 有权限的当前操作员必须核对自己登录账号的密码才能强制清空未结账手牌；只清空当前手牌，撤销消费、返还库存并保留审计记录。不是共用默认清空密码。
- 门票、服务、商品和挂失费变价时自动重算所有未结账账单；已结账价格快照保持不变。
- 基础门票、服务/商品点单，耗材在加单弹窗中选择并记录使用频次，撤销时按原记录返库。
- 单手牌/多手牌合并结账、现金/微信/支付宝/储值混合支付。
- 58mm结账小票及指定岗位下单小票、独立权限补打范围；每日清理只清理过期小票及补打记录，不删除财务和审计。
- 手机号会员识别；会员主页明确区分储值卡与次卡；储值金额确认后进入独立支付页，现金/微信/支付宝收款完成即到账，无需开班。
- 支持实体卡开通会员、原手机号会员补卡；D5键盘读卡器按数字加回车查询。同一会员刷卡和手机号消费使用相同余额/次数，补卡后旧卡不能继续消费。等待刷卡的回车只查询，不自动付款。
- 结账不记忆上一次会员；按手机号精确查询或主动打开刷卡窗口。次卡只抵符合条件的独立门票，剩余金额可组合支付。
- 商品入库、报损、调整、预警和完整库存流水。
- 服务和可售商品可维护名称、价格与状态；独立库存按基本单位结存，支持包装规格、成本、分页、归档和入库数量15%预警。启动或更新不会重置真实库存。
- 可视化经营报表分离消费净营收、会员充值和储值核销，并以“实际新增资金流入”合并展示且排除储值重复流水。
- Socket.IO 多终端实时刷新、事务锁和幂等结账。
- 审计记录以登录用户名作为员工 ID，操作功能显示中文；日志采用哈希链防篡改，并提供自动测试、数据库迁移、备份脚本和 Windows 打包。
